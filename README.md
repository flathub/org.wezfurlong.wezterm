The flatpak metadata covers stable and beta WezTerm versions.

Stable are build from release tags, beta versions are cut from [`main`](https://github.com/flathub/org.wezfurlong.wezterm/tree/beta) branch once there is something to test for users.

* [Installing beta release](https://docs.flathub.org/docs/for-users/installation#flathub-beta-repository)
* [Releasing new version](https://docs.flathub.org/docs/for-app-authors/maintenance)
